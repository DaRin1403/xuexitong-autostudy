# 模块:练题自测(复习 / 错题复盘)

> 本文讲的是**平时练习与复习**场景下怎么用这套工具:自己做题、AI 给答案与解析、错题复盘、题库沉淀。
> 配套工具:[`tools/自检-答题记录检查.js`](../tools/自检-答题记录检查.js)(零依赖 Node 脚本) · 相关模块:[自动答题](模块-自动答题.md)

## ⚠️ 先看这条红线

**本模块只用于平时练习、考前自测、错题复盘。**

- ❌ 不要在**正式考试**(期末考试、准入考试、有承诺书/人脸识别的考试)中使用;
- ❌ 不要让 AI **代替你点击**答案(理由见第 4 节:自动化点击是"软件代考"最直接的证据);
- ✅ 正确用法:AI 当"随叫随到的讲解老师",**判断和操作永远是你自己**。

---

## 1. 三种玩法(按投入从低到高)

| 玩法 | 适合 | 你需要做的 | AI 出多少力 |
|------|------|-----------|------------|
| **A. 脚本全自动** | 章节测验、学习检测、作业 | 打开页面、点开始 | 自动答题并提交(见[自动答题模块](模块-自动答题.md)) |
| **B. 双屏答疑** | 模拟卷、随机卷、课外题库 | 翻题 + 点选 | 读题 → 答案 + 解析 |
| **C. 题库沉淀** | 期末复习、错题本 | 导出记录 | 归类考点、生成复习清单 |

三种可以叠加:**A 先把课程任务做完** → **B 针对薄弱章节刷题** → **C 把错题做成复习资料**。

## 2. 玩法 B:双屏答疑(本模块的核心)

### 2.1 布置

```
┌─────────────────┬─────────────────┐
│  左屏:题目页面    │  右屏:AI 对话    │
│  (学习通/题库)    │  (DSH / 任意 AI) │
└─────────────────┴─────────────────┘
```

- 单显示器也行:左右分屏,或者 AI 用手机/平板;
- **读题方式**:AI 通过浏览器桥接直接读当前页面(你不用截图、不用复制粘贴);
- **省 token 技巧**:读页面时只读题目区域,别读整页——

  ```
  .TiMu, .questionLi, .mark_table     ← 学习通测验/作业/答题卡
  ```

  页面上常有大量与题目无关的水印、导航文本,限定 selector 能省掉 90% 的无效内容。

### 2.2 节奏(实测)

- **每题 15~30 秒**:AI 读题 + 给答案 + 一句理由;你看一眼就点;
- 一份 50 题的模拟卷,大概 **20~30 分钟**走完(含你自己思考);
- **别追求"秒答"**:练习的价值在于你看了理由之后能记住,而不是刷完。

### 2.3 记录(为第 5 节的自检准备)

让 AI 用**固定格式**输出答案,同时你自己(或让 AI)往一个文本文件里记一行:

```
第12题 → CD
第13题 → A
```

这个文件就是自检工具的输入。**格式固定**,后面才能自动查漏、查题型错误。

## 3. 玩法 A:脚本全自动(复习时怎么用)

主脚本的做题引擎在**章节测验/学习检测/作业页**是全自动的,复习期一样能用来"过一遍题":

1. 面板 ⚙ 把 `minAccuracy`(最低正确率)调高,比如 `0.9`——这样脚本**只填不交**,相当于帮你把答案填好,你自己看一遍再决定提交;
2. 或者直接正常用:答完自动提交,提交后**用导出功能把题目+答案存档**(第 6 节),这就是你的错题库。

## 4. 人机分工(为什么不让 AI 代点)

| 环节 | AI | 你 |
|------|-----|-----|
| 读题、解析 | ✅ | — |
| 给答案 + 理由 | ✅ | 判断是否认同 |
| **点击选项 / 提交** | ❌ **永远不做** | ✅ 必须本人 |
| 复盘、归类考点 | ✅ | 决定复习重点 |

**为什么不让 AI 代点**:自动化的点击时序、无鼠标轨迹、精确坐标,在平台日志里就是最直白的"机器操作"证据;而"你在自己看着答案点"和"程序替你作答",性质完全不同。练习场景没必要冒这个险,正式考试更不能。

## 5. 自检:交卷前 / 复盘前跑一遍

工具:`tools/自检-答题记录检查.js`

```bash
node tools/自检-答题记录检查.js 答题记录.txt --total=50 --single=1-15 --multi=16-30 --judge=31-50
```

参数说明:`--total` 总题数、`--single/--multi/--judge` 各题型题号区间(可省略,省略即跳过该题型校验)。

**它会检查 5 件事**:

1. **漏题** —— 哪些题号没有记录;
2. **多选题只填了一个选项** —— 多选必须 ≥2 项,只填 1 个 = 必错;
3. 单选题给了多个选项 / 判断题答案不是 对-错;
4. **连续 5 题以上同答案** —— 人手动点选时最容易漏点、串位的地方;
5. 同一题出现**互相矛盾**的记录。

实测输出(真实案例):

```
⚠️ 发现 3 个问题：
  1. 漏题：第 5、6、7…30 题（共 15 题没记录）
  2. 第 24 题是多选，却只有 1 个选项（B）——多选必须 ≥2 项，单选即错
  3. 第 35~39 题连续 5+ 题答案都是「错」——复核这几题在答题卡上是否真的都点上了
```

> 这个工具是踩坑产物:上面三条全部来自真实案例——一道多选题只填了一个字母、判断题连续 9 题同答案导致漏点。**AI 给的答案再好,点漏一样丢分。**

## 6. 错题复盘(题库沉淀)

主脚本每答完一题就把 `题面 / 选项 / 答案` 存进本地(`cxQuestions`,上限 5000 条),面板可一键导出 JSON。复习期这样用:

1. **导出** → 得到一份 `[{"q":"题面","t":"题型","o":"选项","a":"答案"}]`;
2. **丢给 AI**:"按考点给这些题分类,列出我错得最多的 3 个考点,每个考点出 5 道同类练习题";
3. **生成复习清单**(建议格式):

   | 考点 | 常见陷阱 | 我的错题数 | 复习动作 |
   |------|---------|-----------|---------|
   | 电气安全 | "低压电也能致命"vs"只能防高压" | 6 | 重做错题 + 查规范原文 |

4. **间隔重复**:错题隔 1 天、3 天、7 天各重做一遍,比一次刷十遍有效。

---

## 7. 复习效率建议

- **先看理由再看答案**:AI 给答案时要求附一句理由,你 3 秒能判断自己对不对;
- **不会就说不会**:让 AI 把"为什么其他选项错"也讲一遍,比只记正确答案强;
- **同一考点连着错**:说明是知识点没懂,回到规范/教材原文,别继续刷题;
- **考前自测**:用课程的"随机卷""模拟卷"功能(如果有)当自测,而不是拿正式考试当练习。

## 8. FAQ

**Q: 这样算作弊吗?**
平时练习、复习自测不算——就像用解析书、问同学一样。**正式考试中使用就是作弊**,而且平台有承诺书、人脸识别、日志,风险极高。

**Q: AI 答案能保证对吗?**
不能。多选题、专业术语题错误率明显更高。请把答案当"参考答案",和自己的判断对照。

**Q: 能不能让它自动读完整个考试页面把所有题都答完?**
技术上能做,但本项目的立场是不做也不提供这种做法:那是代考,不是复习。

**Q: 记录文件一定要手写吗?**
不用,让 AI 每答一题就按 `第N题 → 答案` 追加一行即可——你只需要在最后跑一次自检脚本。
