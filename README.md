# 学习通(超星)刷课助手

> 一个油猴(Tampermonkey)脚本,自动完成学习通(超星)课程任务点。
> **零基础可用**:不用写一行代码,装两个东西,填一个 Key,打开课程页就自动干活。

---

## ⚠️ 使用前必读(风险提示)

- 学习通平台已声明使用 **AI、大数据技术监控**"刷课"行为,并可能**通报学生所在高校**;一经查实,学校可给予警告直至开除学籍等处分。
- 本脚本内置了**拟人化防检测**配置(原速播放、随机延迟、故意答错率、每日时长上限),请保持默认值,不要为了快而关闭它们。
- 本项目仅供个人学习辅助与技术研究,使用产生的一切后果由使用者自行承担。

## ✨ 功能一览

| 功能 | 说明 |
|------|------|
| 📺 视频挂机 | 原速静音连播,播完自动下一个,自动切章;中途弹题自动答完继续 |
| 🎵 音频任务 | 静音自动播放到结束 |
| 📄 文档/图片任务 | 自动滚动停留,看完即完成 |
| 📝 章节测验自动答题 | 提取题目 → **字体加密自动解密** → DeepSeek AI 作答 → 正确率达标自动提交 |
| ❓ 视频弹题自动作答 | 判断题/单选题/多选题自动勾选,答完自动继续播放 |
| 🎭 拟人化防检测 | 倍速上限、作答随机延迟、故意答错率(默认 8%)、每日时长上限(默认 4 小时) |
| 🔄 自动更新 | 更新走 jsDelivr CDN,脚本空闲时自动刷新升级(需开启油猴自动检查更新) |

## 🚀 快速开始(5 分钟,零基础)

一共三步:**装油猴 → 装脚本 → 填 AI Key**。

### 第 1 步:安装 Tampermonkey(油猴)

油猴是浏览器的"脚本运行器",装一次永久使用。**Windows 和 Mac 操作一样**,选你正在用的浏览器:

<details>
<summary>🔵 Microsoft Edge(Windows 自带,推荐 Windows 用户)</summary>

1. 打开 Edge 应用商店搜索「**Tampermonkey**」(中文名"篡改猴"),点安装
2. 安装后,**Edge 设置里必须开启「允许用户脚本」**:
   - 地址栏输入 `edge://extensions` 回车
   - 找到 Tampermonkey → 点「详细信息」
   - 把「**允许用户脚本**」开关打开(不开脚本不会运行!)
</details>

<details>
<summary>🟢 Google Chrome(Windows / Mac 通用)</summary>

1. 打开 Chrome 网上应用店(需要能访问 Google),搜索「**Tampermonkey**」安装
2. 开启「允许用户脚本」:
   - 地址栏输入 `chrome://extensions` 回车
   - 找到 Tampermonkey → 点「详细信息」
   - 打开「**允许用户脚本**」开关
</details>

<details>
<summary>🧭 Safari(仅 Mac)</summary>

1. 打开 App Store,搜索「**Tampermonkey**」,安装(收费约 12 元)
2. 安装后打开 Safari 的「设置 → 扩展」,勾选启用 Tampermonkey
3. Safari 的油猴是独立 App,脚本安装流程与 Chrome/Edge 相同
</details>

> 💡 不确定装对没有?随便打开一个网页,点浏览器右上角的油猴图标,能弹出菜单就是装好了。

### 第 2 步:安装本脚本

**方法一(推荐,一键):** 点击下面这个链接,油猴会自动弹出安装窗口,点「安装」即可:

👉 **https://cdn.jsdelivr.net/gh/DaRin1403/xuexitong-autostudy@main/学习通刷课助手.user.js**

> 仓库刚发布时 CDN 需要几分钟同步,若打不开请稍等重试。

**方法二(手动):** 下载本仓库的 `学习通刷课助手.user.js` 文件 → 点浏览器油猴图标 → 「管理面板」→ 左上角「**+**」新建脚本 → 清空编辑器内容 → 把文件内容全部粘贴进去 → `Ctrl+S`(Mac 是 `Cmd+S`)保存。

装好后,油猴管理面板里应该能看到「学习通刷课助手」且开关为开启状态。

### 第 3 步:配置 AI Key(做题必需,2 分钟)

章节测验的自动答题靠大模型完成,需要一个 OpenAI 兼容接口的 API Key。**支持 DeepSeek、MiniMax、智谱、硅基流动、通义千问、Kimi 等多个平台**,任选其一即可。

- 推荐 **DeepSeek**(便宜、准):注册 → 创建 Key → 复制 `sk-` 开头的密钥 → 打开学习通课程页 → 面板「⚙」→ 勾选「AI 答题」→ 粘贴 Key → 保存
- **各平台的详细获取图文教程(注册地址、接口地址、模型名、免费额度)→ [📄 docs/get-api-key.md](docs/get-api-key.md)**

> Key 只保存在你自己的浏览器里,不会上传到任何地方。

## 📖 使用说明

### 学习通网页版入口(重要)

> ⚠️ 直接百度搜"学习通"出来的多是 App 下载页,不直观。**直接用下面这个链接:**

👉 **学习通(超星)网页版登录:https://i.chaoxing.com**

- 打开后自动跳转到登录页,用**手机号 + 密码**登录即可
- 登录后进入「个人空间」→「我学的课」→ 点开课程,就进入章节学习页了
- 本脚本只在网页版上运行,App 和 Windows 客户端不支持

### 挂机步骤

1. 打开上面的登录链接,登录学习通
2. 进入任意课程 → 打开章节学习页
3. 页面右下角出现粉色「**📚 学习通刷课助手**」面板 = 已开始自动挂机
4. 什么都不用做,挂机即可。浏览器可以最小化,不影响你用电脑(视频已静音)

### 面板按钮说明

| 按钮 | 功能 |
|------|------|
| ▶ / ⏸ | 开始 / 停止挂机(待机时显示 ▶,工作中显示 ⏸) |
| ▼ / ▲ | 展开 / 收起日志 |
| ⚙ | 打开设置面板(每项配置都带说明) |
| 表头空白处 | 按住可拖动面板位置 |

### 设置项说明

| 设置 | 默认值 | 说明 |
|------|--------|------|
| 视频倍速 | 1(原速) | 最高 1.5,越高检测风险越大,**建议保持 1** |
| AI 答题 | 关 | 开启后测验自动作答(需填 Key) |
| AI Key | 空 | 任意 OpenAI 兼容平台的密钥,获取方法见 [docs/get-api-key.md](docs/get-api-key.md) |
| AI 模型 | deepseek-reasoner | 最准;deepseek-chat 更快更便宜;其他平台模型名见上述文档 |
| AI 接口地址 | DeepSeek 官方 | 换平台时改成对应地址,见上述文档 |
| 故意答错率 | 8% | 拟人化:真人不会全对。判断题反着点、单选点错项;填 0 关闭 |
| 每日上限 | 240 分钟 | 今天刷满自动停止,明天恢复;防止"一天刷完"的异常曲线 |
| 自动提交测验 | 开 | 正确率 ≥60% 才提交,不足自动暂存(不乱交卷) |
| 自动切章 | 开 | 本章完成后自动进入下一章 |

## ❓ 常见问题(FAQ)

**Q: 打开课程页没有出现粉色面板?**
A: 依次检查:① 油猴已安装且脚本开关开启;② 浏览器扩展设置里「允许用户脚本」已打开;③ 按 F5 刷新页面。

**Q: 视频不自动播放?**
A: 浏览器禁止网页自动放声音。在页面上随便点一下鼠标,之后全程自动(脚本已静音,不会吵)。

**Q: 弹出"微信扫码验证"?**
A: 这是学习通的人工验证,任何脚本都过不了。**本人扫码**,扫完脚本自动继续。

**Q: 提示"今日视频任务点完成数已达上限"?**
A: 学习通平台每日限制(不是脚本限制),今天视频不计分了,明天恢复;学习检测不受影响。

**Q: 测验显示"未查到答案"?**
A: 检查 AI Key 是否配置并勾选了 AI 答题。冷门题也可能答不上,脚本会自动暂存不提交(不会乱交卷)。

**Q: 字体加密是什么?**
A: 学习通把题目文字用自定义字体打乱防抄题。本脚本已内置自动解密(Canvas 字形对比法),无需理会。

**Q: 开着梯子(全局代理)时 AI 答题全部失败,日志提示"未查到答案"?**
A: DeepSeek / MiniMax / 智谱等都是**境内服务**。全局代理会把 API 请求劫持到境外节点,节点连国内接口直接失败(学习通有直连白名单所以正常)。解决:① 刷课期间退出梯子(最省事);② 或梯子切**规则模式**,并把所用平台的 API 域名(如 `api.deepseek.com`、`api.minimaxi.com`、`open.bigmodel.cn`)加入**直连白名单**。

**Q: 怎么更新脚本?**
A: 油猴管理面板 → 设置 → 「脚本更新间隔」设为最短。之后更新全自动:作者发版 → 油猴自动拉取 → 脚本空闲时自动刷新。

**Q: 考试能用吗?**
A: **不建议,风险极高。** 本脚本不包含考试页功能,也请不要在考试时使用。

## 🔒 安全与合规建议

1. **倍速保持 1x**:挂机就是挂机,让视频真实走完
2. **每日刷课 ≤ 4 小时**,一门课分几天刷完
3. **正常时段**刷课,不要整夜挂机
4. **刷课时手机 App 退出登录**(平台点名"多终端"检测)
5. 测验偶尔留错题(默认已做),不要门门满分
6. 考试不碰脚本
